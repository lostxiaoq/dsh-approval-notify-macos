# Security Policy

## Supported versions

Security fixes are applied on the latest release of `dsh-approval-notify-macos` (currently 0.1.x).

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Preferred options:

1. Open a **private security advisory** on this repository via GitHub: **Security → Advisories → Report a vulnerability** (or the repository Security tab).
2. If that is unavailable, open a GitHub issue and label it `security`, or contact the maintainer through the GitHub Security tab / contact options listed on the repository.

Include steps to reproduce, affected versions, and impact. We will acknowledge reports and coordinate a fix and disclosure timeline.
